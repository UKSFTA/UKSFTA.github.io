# UKSFTA

Technical portal for UKSF Taskforce Alpha. Hosts the unit website and
project documentation.

## Projects

- [UKSFTA-Tools](https://github.com/UKSFTA/UKSFTA-Tools): DevOps suite.
- [UKSFTA-Bot](https://github.com/UKSFTA/UKSFTA-Bot): Discord bot.
- [UKSFTA-BIS](https://github.com/UKSFTA/UKSFTA-BIS): Arma file format library.
- [UKSFTA-Mods](https://github.com/UKSFTA/UKSFTA-Mods): Unit mod collection.
- [UKSFTA-Maps](https://github.com/UKSFTA/UKSFTA-Maps): Training theatres.

## Development

This site is built with [Hugo](https://gohugo.io/) and the
[GOV.UK Frontend](https://frontend.design.service.gov.uk/) design system.

### Prerequisites

- Hugo (Extended Version) v0.155.3+
- Node.js and NPM

### Local Development

```bash
npm install
hugo server
```
